# Forecast Platform — презентационное описание продукта

## 1) Короткий питч (30–60 секунд)
**Forecast Platform** — это единая веб-платформа для работы с солнечными станциями: от управления организациями и командами до загрузки истории, обучения моделей, расчёта прогноза и автоматической рассылки отчётов.  
Платформа помогает операторам СЭС быстрее получать надёжный прогноз генерации и принимать решения на основе данных.

---

## 2) Что уже реализовано (по блокам)

### A. Управление пользователями и доступом
- Регистрация, вход/выход, базовая авторизация в веб-интерфейсе.
- JWT API-авторизация для интеграций (`register/login/refresh/me`).
- Мультиорганизационная модель:
  - организация с владельцем;
  - роли участников: **owner/admin/analyst/viewer**;
  - приглашения в организацию (создать, принять, переотправить, отозвать);
  - ограничение частоты отправки приглашений.
- Логика подписки и trial-периода:
  - состояния (`trialing`, `active`, `past_due`, `canceled`);
  - контроль прав на запись данных в зависимости от статуса.

### B. Работа со станциями
- Создание и редактирование станций.
- Сортировка станций (перемещение вверх/вниз в списке).
- Карточка станции с рабочими действиями.
- Поддержка техпараметров станции (мощность, география, ориентиры и др.).
- Экспорт «план/факт» и исторических данных.

### C. Исторические данные
- Загрузка истории по станции (CSV/XLSX).
- Нормализация дат и защита от типичных ошибок парсинга.
- Хранение истории в двух контурах: **main** и **test**.
- Автоподхват истории из папки (share/fallback), мониторинг и автообновление.

### D. Прогнозирование
- Обучение и использование моделей прогноза (NeuralProphet + XGBoost + эвристика).
- Ансамбль прогнозов в итоговое значение (`pred_final`).
- Учет погодных факторов и сезонных корректировок.
- Поддержка погодных провайдеров (Open-Meteo / Visual Crossing).
- Работа с отдельными контурами прогноза: **main** и **test**.

### E. Планировщик и отчётность
- Настройка расписания автопрогноза по станции:
  - включение/выключение;
  - время запуска;
  - горизонт прогноза;
  - список email-получателей.
- Ручной запуск прогноза из интерфейса.
- Формирование Excel-отчёта по прогнозу.
- Email-рассылка отчёта получателям.
- Хранение истории сгенерированных отчётов.

### F. API и интеграция
- REST API для организаций, участников, приглашений и станций.
- Endpoint загрузки истории для внешних систем.
- Единые правила прав доступа на уровне организаций/ролей.

## 3) Ценность для бизнеса (слайд «Зачем это нужно»)
- **Снижение ручного труда**: меньше ручной подготовки файлов и отчётов.
- **Ускорение планирования**: оперативный прогноз выработки на несколько дней.
- **Прозрачность для команды**: роли, доступы, приглашения, единая рабочая среда.
- **Масштабируемость**: поддержка нескольких организаций и множества станций.
- **Готовность к интеграции**: API + JWT для подключения внешних сервисов.

---

## 4) Демонстрационный сценарий (7–10 минут)
1. Вход в систему и обзор списка станций.  
2. Создание новой станции и базовая настройка.  
3. Загрузка истории (или запуск автообновления).  
4. Запуск обучения/прогноза вручную.  
5. Просмотр списка прогнозов и экспорт в Excel.  
6. Настройка расписания и email-получателей.  
7. Коротко показать API-возможности (JWT + станции/организации).
