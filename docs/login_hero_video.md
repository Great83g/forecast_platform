# Видео на странице авторизации: куда класть и как называть

Ниже принятый формат для фонового видео в правой части страницы входа (`templates/accounts/login.html`).

## Зачем это нужно

Видео на логине нужно не для функционала входа, а для UX/презентации:

- визуально сразу показывает домен продукта (солнце/ветер/генерация);
- делает экран входа более «живым» для демо и презентаций;
- усиливает бренд (пользователь понимает, куда попал, до авторизации).

Если на конкретном сервере важнее скорость/экономия трафика, видео можно заменить на статичный постер:

- оставить только `login-background.png`;
- указать несуществующий или пустой `LOGIN_HERO_VIDEO_URL` — сработает визуальный fallback на постер.

## Куда загружать

- Основной файл видео: `media/login-hero.mp4`
- Постер (статичная картинка, пока видео не стартовало): `media/login-background.png`

Именно эти пути сейчас используются в шаблоне авторизации:

```html
<video autoplay muted loop playsinline poster="/media/login-background.png">
  <source src="/media/login-hero.mp4" type="video/mp4">
</video>
```

## Именование (чтобы не путаться)

Для этой страницы держим фиксированные имена:

- `login-hero.mp4` — финальное продакшн-видео
- `login-background.png` — финальный постер

Если делаете новую версию ролика, храните рабочие варианты рядом с версией в суффиксе, например:

- `login-hero.v2.source.mp4` (черновик)
- `login-hero.v3.source.mp4` (черновик)

После согласования **переименовывайте финал обратно** в `login-hero.mp4`.

## Рекомендованные параметры видео

- Формат: H.264 + AAC (`.mp4`)
- Длительность: 8–20 секунд
- FPS: 24–30
- Размер: до ~8–12 MB (чтобы не тормозило на мобильных)
- Контент: без резких вспышек, так как видео играет в фоне циклически

Пример сжатия через ffmpeg:

```bash
ffmpeg -i input.mp4 -vf "scale=1920:-2" -r 30 -c:v libx264 -crf 24 -preset medium -pix_fmt yuv420p -movflags +faststart -an media/login-hero.mp4
```

## Чек-лист после замены

1. Откройте `/login/` и проверьте, что видео запускается автоматически.
2. Проверьте, что без видео виден постер `login-background.png`.
3. Проверьте мобильный вид (видео не должно ломать layout).
4. Если ролик слишком "тяжёлый" — уменьшите `crf`/разрешение и перегенерируйте.
