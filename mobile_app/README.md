# Forecast Mobile App (Flutter)

Базовый каркас Flutter-приложения добавлен в репозиторий.

## Локальный запуск

1. Установите Flutter SDK (stable) и Android SDK.
2. В каталоге `mobile_app` выполните:

```bash
flutter pub get
flutter run
```
